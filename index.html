// TRANSPARENCY & FAQ

How The Assessment Works

Everything you need to know before authorizing a cybersecurity scan.

1. What am I buying for R500?
You are purchasing a defined, focused vulnerability assessment of your single designated website URL. This includes automated scanning supplemented with manual checks against common web security risks, culminating in a clear, written findings report with steps on how to secure your site.
2. What gets tested during the check?
We perform agreed security checks based on OWASP (Open Web Application Security Project) standards. Checks may include common web security risks, security headers, SSL/TLS configuration, software versions, and exposed sensitive directories, within the scope authorized in writing.
3. Can you damage my website during testing?
Testing is planned to be non-destructive. Denial of Service testing, modifying production data, or actions likely to disrupt service are excluded unless separately agreed in writing with appropriate safeguards. No test can guarantee zero operational risk.
4. Do I need to give permission?
Yes, written authorization is strictly required. Testing requires explicit consent from the legal owner or authorized representative. Before testing, a written scope and authorization must be agreed.
5. What do I receive after the audit?
You will receive a confidential report detailing:
  • Executive summary for non-technical readers
  • Risk ratings and technical findings
  • Evidence appropriate to the authorized scope
  • Prioritized recommendations to address findings
6. Does the R500 price include fixing the issues?
No. The R500 covers the agreed security assessment and report. Repairs or code changes are quoted separately depending on complexity and who implements the fixes.
7. When do I pay for the audit?
Payment terms are agreed before testing begins. The finalized findings report is provided after testing is complete and the agreed payment terms are met.
